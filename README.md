# Resume

A personal resume project built with HTML and CSS. This repository is focused on presenting resume content in a clean web format while practicing layout, spacing, and visual structure.

## Purpose

- Build a browser-based resume page
- Practice semantic HTML structure
- Improve CSS styling and page layout
- Keep professional information organized in a web-friendly format

## Tech Stack

- HTML
- CSS

## Status

This project is part of my frontend practice and personal portfolio cleanup. It is intentionally simple, with the focus on clear structure and presentation.
